# DrawRelay

DrawRelayは、2人で通信しながら遊ぶWindows向けのお絵描き当てゲームです。

一方のプレイヤーが出題されたお題を描き、もう一方のプレイヤーが回答します。正解またはスキップすると、描く側と回答する側が交代します。

## 主な機能

- TCP通信による2人対戦
- マウスを使ったリアルタイム描画
- 黒、赤、茶、黄、青、緑のペン
- 消しゴムと全消し
- 回答の正誤判定
- 正解時の役割交代
- お題のスキップ
- 切断要請と切断

現在のお題は次の3種類です。

- いぬ
- ねこ
- うさぎ

## 動作環境

- Windows
- Visual Studio 2019以降、またはMSVC Build Tools
- 「C++によるデスクトップ開発」ワークロード
- Windows SDK
- 日本語を扱えるWindowsのANSIコードページ

このアプリはWin32 APIと従来のWinsock APIを使用しています。現時点ではWindows以外のOSには対応していません。

## ビルド

Visual Studioの「x64 Native Tools Command Prompt」を開き、リポジトリのルートで次を実行します。

```bash
cl /nologo /EHsc /D_MBCS DrawRelay.cpp user32.lib gdi32.lib wsock32.lib /link /SUBSYSTEM:WINDOWS /OUT:DrawRelay.exe
```

成功すると、リポジトリのルートに `DrawRelay.exe` が生成されます。

主なオプションの意味は次のとおりです。

- `/EHsc`: C++の例外処理を有効化
- `/D_MBCS`: Win32 APIをANSI文字列として使用
- `/SUBSYSTEM:WINDOWS`: Windows GUIアプリとしてリンク
- `/OUT:DrawRelay.exe`: 出力ファイル名を指定

ビルド生成物はGitの管理対象外です。

## 遊び方

### 同じPCで試す場合

1. `DrawRelay.exe` を2つ起動します。
2. 片方の画面で「接続待ち」を押します。
3. もう片方の「Host Name」に `localhost` を入力します。
4. 「接続」を押します。
5. 画面右下に表示された役割に従って、描画または回答します。

接続待ち側がお絵描き側、接続側が回答側として開始します。

### 別のPCと接続する場合

1. 2台のPCを同じネットワークへ接続します。
2. お絵描き側のPCで「接続待ち」を押します。
3. 回答側のPCで、接続待ち側のホスト名またはIPアドレスを入力します。
4. 「接続」を押します。

接続できない場合は、Windows DefenderファイアウォールでTCPポート `10000` の受信が許可されているか確認してください。

## ゲームの進行

- お絵描き側にはお題が表示されます。
- 回答側は回答欄へ答えを入力し、「回答」を押します。
- 正解すると描画内容が消去され、両プレイヤーの役割が交代します。
- 不正解の場合は役割を維持したまま続行します。
- お絵描き側が「スキップ」を押すと、新しいお題で役割が交代します。

## 開発時の確認

ファイルを生成せずに構文チェックだけ行う場合は、次を実行します。

```bash
cl /nologo /Zs /W4 /EHsc /D_MBCS DrawRelay.cpp
```

現在はエラー0件で構文チェックを通過します。未使用引数、整数変換、変数名の隠蔽に関する警告が残っています。

## 通信上の注意

- TCPポート `10000` を使用します。
- 同時に接続できる相手は1人です。
- 認証や通信の暗号化には対応していません。
- インターネットへ直接公開せず、信頼できるローカルネットワーク内で使用してください。
- 日本語のお題と固定長メッセージは、現在のANSI文字コードを前提としています。

## 既知の制約

- ビルド用のVisual StudioプロジェクトやCMake設定はまだありません。
- アプリ本体は単一のC++ファイルで構成されています。
- 描画履歴は最大10,000点の固定配列です。
- コンパイラ警告が残っています。
- TCPメッセージの分割・結合に対する堅牢化は未対応です。
- ウィンドウクラス名と一部の表示名には旧名称が残っています。
